**作品名稱：QWER 青春樂團圖鑑**

1. **網站目標與使用對象**

   製作一個以繁體中文介紹 QWER 的互動網站，讓原本不認識她們的人，能透過成員資料、完整歌曲庫與音樂播放認識團體。網站也提供歌曲收藏與編輯工具，方便訪客保存喜好，並讓製作者日後自行收錄新歌。

2. **視覺風格與頁面安排**

   採用青春樂團風，以明亮淺色背景、成員照片、彩色標籤及樂器元素呈現，搭配適量的切換動畫。網站須適應電腦與手機畫面，文字清楚、按鈕容易點擊。

   採單頁式設計，內容依序為：

   | 區域 | 內容 |
   |---|---|
   | 首頁與團體簡介 | 團體照片、簡短介紹、前往成員區與歌曲區的按鈕 |
   | 成員介紹 | Q／W／E／R 切換按鈕、照片及個人資料 |
   | 歌曲探索 | 完整歌曲庫、搜尋、專輯篩選、排序及播放器 |
   | 我的收藏 | 集中查看已收藏歌曲，可播放或取消收藏 |
   | 歌曲編輯工具 | 新增、修改歌曲資料，預覽及匯出新版網站 |
   | 頁尾 | 資料來源、歌曲資料更新日期與非官方粉絲作品說明 |

3. **成員介紹功能**

   介紹 Chodan、Magenta、Hina、Siyeon 四位成員。每位成員包含藝名、照片、生日、星座、樂團定位、代表字母、代表色、代表動物與簡短介紹。

   訪客可點擊 Q／W／E／R 按鈕切換成員；電腦也支援對應鍵盤按鍵。切換時，照片、資料及卡片裝飾色一起更新，並明確標示目前選取的成員。使用者正在搜尋或填寫表單時，字母快捷鍵不觸發切換。

   資料優先查核官方網站及官方社群。星座依生日對應；代表色、動物等資訊若無法找到官方確認，須標示來源與確認情況。

4. **歌曲收錄範圍**

   初始歌曲庫收錄截至 **2026 年 10 月 14 日，QWER 以團體名義正式發行的所有曲目**，包含專輯主打、收錄曲、單曲、合作曲、正式發行的翻唱、其他語言版本、混音版、純演奏版，以及正式曲目表中的 Intro、Outro。

   僅在直播或現場演出、尚未正式發行的歌曲不列入初始清單；成員個人名義發行的作品也不自動納入。

   同曲同版本若出現在不同專輯，只建立一筆歌曲資料，保留其收錄專輯資訊；不同語言或不同編曲版本分別標示。初始清單須逐張核對官方發行資訊，完成後才統計歌曲總數。

5. **歌曲探索與播放功能**

   每首歌曲顯示封面或預設圖、原文歌名、已確認的英文名稱、可取得的中文譯名、收錄專輯、發行日期、版本、簡短介紹、播放按鈕與收藏愛心。中文譯名須區分官方名稱與網站提供的翻譯。

   提供歌名搜尋、專輯篩選及發行日期由新到舊／由舊到新排序。搜尋可比對已收錄的韓文、英文及中文名稱，並能與專輯篩選同時使用。找不到符合條件的歌曲時，顯示提示及清除篩選按鈕。

   網頁使用一個共用 YouTube 播放器。訪客選歌後載入對應影片，由訪客啟動播放；切換歌曲時停止原本的影片，避免同時播放多首。

   播放來源優先使用官方 MV，其次為官方授權音源或官方演出影片，並標示來源類型。沒有可用官方來源時，仍保留歌曲資料，顯示「暫無可播放來源」。播放器旁保留前往 YouTube 的連結，供嵌入播放受限時使用。

6. **最愛歌曲收藏**

   點愛心即可加入收藏，再點一次取消。歌曲卡片與收藏區的狀態須同步，且同一首歌曲不可重複收藏。

   收藏保存在瀏覽器本機儲存空間；正常儲存可用時，同一裝置、同一瀏覽器重新開啟網站後仍會保留。收藏不跨裝置同步，清除網站資料後會移除。尚未收藏任何歌曲時，顯示引導提示。

7. **歌曲編輯工具**

   提供填表式介面，讓製作者新增或修改歌曲，無須直接編輯程式。表單欄位如下：

   | 欄位 | 規則 |
   |---|---|
   | 原文歌名 | 必填 |
   | 英文名稱、中文譯名 | 選填，未確認時可留白 |
   | 收錄專輯／單曲名稱 | 必填，可新增專輯名稱 |
   | 發行日期 | 必填，使用有效日期 |
   | 版本 | 預設原版，可填日文版、混音版、純演奏版等 |
   | YouTube 連結 | 選填，填寫時須符合支援的網址格式 |
   | 播放來源類型 | MV、官方音源或官方演出 |
   | 封面圖片連結 | 選填，未填或載入失敗時使用預設圖 |
   | 簡短介紹、資料來源連結 | 選填 |

   儲存前檢查必填欄位、日期與網址格式，並提示可能重複的歌名及版本。新增的專輯須自動出現在篩選選項中；修改既有歌曲時，維持其識別碼，避免收藏失去對應。

   編輯結果先在目前瀏覽器預覽與保存。若本機儲存不可用，須顯示提示，讓使用者及時匯出檔案。

8. **匯出與日後更新**

   提供「匯出更新版網站」按鈕，產生包含完整 HTML、CSS、JavaScript 與最新歌曲資料的單一 `index.html`。

   匯出內容包含網站公開資料，不包含個人的最愛收藏、搜尋條件或當下播放狀態。匯出的檔案再次開啟後，仍可使用編輯工具並繼續匯出。

   日後更新流程為：

   **新增或修改歌曲 → 預覽確認 → 匯出 `index.html` → 上傳 GitHub 取代舊檔 → 確認公開網站更新成功。**

   瀏覽器中的編輯不會直接改動公開網站；新版須透過 GitHub 儲存庫發布，其他訪客才會看到更新。[GitHub Pages 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

9. **技術與使用條件**

   最終只交付一份 `index.html`，CSS 與 JavaScript 均寫在檔案內，不需要後端伺服器、資料庫或登入帳號。網站以 GitHub Pages 公開，圖片及 YouTube 播放可使用外部來源，因此完整影音體驗需要網路。

   按鈕須可使用鍵盤操作，圖片提供替代文字，選取與收藏狀態不能只靠顏色區分。手機版不得出現影響操作的橫向溢出。
